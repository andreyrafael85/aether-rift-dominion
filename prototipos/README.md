# Protótipos antigos

Guardados aqui para a história do projeto; o jogo não usa nada desta pasta.

| Pasta | O que é |
|:--|:--|
| `style/` | a prova de conceito visual 2D (sprites voxel isométricos, beta 1.5). O build gera dela o `estilo.html` da raiz. |
| `style3d/` | a validação do caminho 3D com Three.js (os mesmos modelos voxel com luz e sombra). O build gera dela o `estilo3d.html` da raiz. |

`estilo.html` e `estilo3d.html` continuam na raiz porque são endereços publicados no GitHub Pages; o `tools/build.mjs` os gera a partir de `prototipos/style/` e `prototipos/style3d/`.
